# Shopify Product Update Workflow

This workflow guides you through updating a Cannibisters product on Shopify with proper metafields, descriptions, and tags.

## Trigger
- Martine notifies you on Slack about a new product loaded onto Shopify

## Steps

### 1. Get Product Information
- Check the Slack notification from Martine
- Note the product/strain name
- Note the product type (Flower, Concentrate, Edible, etc.)

### 2. Research Strain Information
If strain information is not provided, research:
- Lineage (parent strains)
- Flowering time
- Profile (Indica/Sativa/Hybrid ratio)
- Height characteristics
- Stretch percentage
- THC levels
- Flavor profile
- Effects
- Breeder information
- Common uses

### 3. Create Metafields Using Template
Use the Cannibisters-style metafield breakdown (see `shopify_product_template.md`):

**Product Metafields:**
- Lineage
- Flowering Time
- Profile
- Height
- Stretch Percentage
- Average THC Levels
- Flavours
- Effects
- Breeder
- Used for

**Category Metafields (for Flowers in Plants):**
- Plant characteristics
- Plant class
- Plant name
- Suitable space

**Short Description:**
- 2-3 sentences capturing essence, flavor, and effects

### 4. Access Shopify Product Page
- Log into Cannibisters Shopify admin
- Navigate to Products
- Find the new product by name
- Open the product editor

### 5. Fill in Product Information

**Description:**
- Paste the short description into the main product description field

**Metafields:**
- Scroll to metafields section
- Fill in all Product Metafields
- Fill in all Category Metafields (if applicable)

**Tags:**
- Add relevant tags based on:
  - Strain type (Indica, Sativa, Hybrid)
  - Effects (Relaxed, Euphoric, Creative, etc.)
  - Flavors (Sweet, Citrus, Earthy, Gas, etc.)
  - Use case (Evening, Daytime, Social, etc.)

### 6. Review and Save
- Double-check all fields for accuracy
- Ensure formatting is consistent with previous entries
- Save the product

### 7. Confirm Completion
- Reply to Martine on Slack confirming the update
- Note any special characteristics or highlights

## Notes
- Always maintain the Cannibisters style and tone
- Keep descriptions concise but evocative
- Use bullet points (•) for effects
- Ensure consistency with previous strain entries
