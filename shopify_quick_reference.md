# Shopify Product Quick Reference

## 🚀 Quick Start

When Martine notifies you about a new product:

1. **Get the strain name** from Slack
2. **Use the template** in `shopify_product_template.md`
3. **Fill in metafields** following the structure
4. **Update Shopify** product page
5. **Confirm** with Martine

## 📋 Essential Metafields Checklist

### Product Metafields (Required)
- [ ] Lineage
- [ ] Flowering Time
- [ ] Profile (Indica/Sativa ratio)
- [ ] Height
- [ ] Stretch Percentage
- [ ] Average THC Levels
- [ ] Flavours
- [ ] Effects
- [ ] Breeder
- [ ] Used for

### Category Metafields (For Flowers)
- [ ] Plant characteristics
- [ ] Plant class
- [ ] Plant name
- [ ] Suitable space

### Description & Tags
- [ ] Short description (2-3 sentences)
- [ ] Tags (strain type, effects, flavors)

## 🎨 Style Reminders

**Effects:** Use bullet points (•) → Relaxed • Euphoric • Happy

**Ranges:** Use en-dash (–) not hyphen → 22–27% not 22-27%

**Tone:** Premium, evocative, concise

**Description:** Flavor + Effects + Use case

## 🔍 Common Strain Types

**Indica-Dominant:** Relaxing, body-focused, evening use
**Sativa-Dominant:** Energizing, cerebral, daytime use
**Balanced Hybrid:** Mix of both effects

## 💡 Quick Tips

- Match the style of previous entries
- Keep descriptions under 3 sentences
- Use sensory language for flavors
- Focus on experience, not just specs
- Double-check spelling and formatting
